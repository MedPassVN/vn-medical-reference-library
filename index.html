Hướng dẫn tích hợp CDN tĩnh

MRef Library hoạt động hoàn toàn như một CDN dữ liệu tĩnh. Dữ liệu siêu dữ liệu (Metadata) được lưu trữ tại `library.json` và các tệp PDF gốc được phục vụ trực tiếp từ CDN hiệu năng cao của GitHub Pages.

API Registry CDN (JSON)
https://.github.io/vn-medical-reference-library/library.json
PDF Asset CDN Base Url
https://.github.io/vn-medical-reference-library/raw_sources/.pdf

Mẫu Code Tích hợp

// Tải danh bạ tài liệu và liên kết CDN tương ứng
const cdnBase = window.location.origin + window.location.pathname.replace(/\/$/, "");

fetch(`${cdnBase}/library.json`)
  .then(res => res.json())
  .then(library => {
    console.log(`Đã tải thành công ${library.length} tài liệu từ CDN.`);
    
    // Ví dụ: Lấy tệp PDF của Thông tư 51
    const ref = library.find(item => item.ref_id === 'REF_MOH_2017_TT51');
    const pdfUrl = `${cdnBase}/${ref.local_path}`;
    console.log(`Link PDF CDN: ${pdfUrl}`);
  });
import requests

cdn_base = "https://<username>.github.io/vn-medical-reference-library"
response = requests.get(f"{cdn_base}/library.json")

if response.status_code == 200:
    library = response.json()
    print(f"Đã tải {len(library)} tài liệu.")
    for document in library:
        if "local_path" in document:
            print(f"[{document['ref_id']}] -> {cdn_base}/{document['local_path']}")
# Tải danh bạ API JSON
curl -X GET https://<username>.github.io/vn-medical-reference-library/library.json \
     -H "Accept: application/json"

# Tải trực tiếp tệp PDF
curl -O https://<username>.github.io/vn-medical-reference-library/raw_sources/REF_MOH_2017_TT51.pdf
