Hướng dẫn Tích hợp CDN

Hệ thống hỗ trợ gọi dữ liệu trực tiếp từ các liên kết tĩnh (static links) bên dưới làm CDN cho ứng dụng:

API Registry CDN (JSON):
PDF Files Base CDN:

Ví dụ Fetch dữ liệu bằng Javascript:

// Tải danh bạ tài liệu từ CDN
const cdnBase = window.location.origin + window.location.pathname.replace(/\/$/, "");

fetch(`${cdnBase}/library.json`)
  .then(res => res.json())
  .then(library => {
    console.log(library);
    // Link PDF: `${cdnBase}/${document.local_path}`
  });
Đã sao chép liên kết vào bộ nhớ tạm!
